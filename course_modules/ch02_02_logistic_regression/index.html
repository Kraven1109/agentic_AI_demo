02_hoi_quy_logistic_churn.py 
import numpy as np
from sklearn.linear_model import LogisticRegression
import statsmodels.api as sm

X = np.array([1, 2, 3, 4, 5, 6, 7, 8]).reshape(-1, 1)
y = np.array([0, 0, 0, 1, 0, 1, 1, 1])

# 1. Nghiệm MLE thuần túy (Tắt phạt chuẩn hóa L2)
clf = LogisticRegression(C=np.inf, solver='lbfgs', tol=1e-8).fit(X, y)
w, b = clf.coef_[0][0], clf.intercept_[0]
print(f"w = {w:.4f}, b = {b:.4f}, x* = {-b/w:.3f}h")

# 2. Kiểm định thống kê qua Statsmodels
logit_res = sm.Logit(y, sm.add_constant(X)).fit()
print(logit_res.summary())
Phương pháp 1: Tại sao OLS thất bại & Cấu trúc Logit

Nếu áp dụng Hồi quy Tuyến tính OLS, đường thẳng vượt ra ngoài miền xác suất hợp lệ [0, 1] (vùng gạch chéo đỏ trên đồ thị khi x < 1.5h hoặc x > 7.5h).

logit(p)=ln(p1−p)=wx+b⇔p=11+e−(wx+b)
⚠️ Sai lầm kinh điển cần tránh: Không thể lấy nhãn thực tế yᵢ ∈ {0, 1} thay vào ln(yᵢ / (1 - yᵢ)) để chạy OLS tuyến tính, vì:
• Khi yᵢ = 1 ⇒ ln(1/0) = +∞
• Khi yᵢ = 0 ⇒ ln(0/1) = -∞
Khoảng cách từ điểm dữ liệu thật tới đường thẳng trong không gian Log-Odds là vô cực! Hãy bấm thử nút "⚡ Trục Log-Odds" phía trên đồ thị để thấy các mũi tên chỉ ra vô cực. Do đó, ta bắt buộc phải ước lượng (w, b) bằng MLE hoặc Gradient Descent.
Phương pháp 2: Hợp lý Cực đại (MLE)

Tìm (w, b) sao cho tích xác suất xảy ra đồng thời của cả 8 kết quả thực nghiệm đạt cực đại:

L(w,b)=∏i=1Npiyi(1−pi)1−yi⇒lnL=∑i=1N[yilnpi+(1−yi)ln(1−pi)]
